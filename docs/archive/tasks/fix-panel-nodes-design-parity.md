# 面板的节点下钻页照设计稿 v0.2：药丸搜索框、可折叠分组、无底框无分隔线的行

## 问题

2026-11-19 作者贴出面板「节点」页的截图：「跟设计稿的风格很不契合」。对照设计稿「菜单栏」一节的节点下钻页（`#pNodes`）：

- 列表是 `List(.inset)`：一块不透明的白底盖在玻璃面板上，每行一条分隔线，右侧一条常驻滚动条；设计稿的行直接铺在面板上，没有底框和分隔线，悬停时才有圆角高亮。
- 搜索框是方角的 `roundedBorder`；设计稿是带放大镜的药丸形，右边并排一个圆形的测速按钮（测全部）。现在测速按钮在每个分组标题里。
- 标题「节点」靠左、返回是裸箭头；设计稿是圆形返回按钮、标题居中。
- 分组标题只有组名；设计稿是「组名 · 手动选择 / 自动测速」加一个折叠箭头，前两组默认展开，其余折叠。现在所有组都摊开，而且只列手动选择的组。
- 选中的节点整行变蓝；设计稿只有对勾是强调色，名称不变色。

`fix-panel-design-parity` 重排了面板首页，没有动这一页。分组的折叠与筛选抽成纯函数。
