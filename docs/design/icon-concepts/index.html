应用图标外观
图形怎么拆进 Icon Composer

A · 双轨 P暖白底上放外轨和内轨两片。两道弯的间距直接画进轮廓，各自的末端保留平切口。

B · 光隙 P以字母内孔为中心沿同一斜线切开。上、下两片分别导入，穿过字干和字肩的空隙由底色露出。

C · 错相复制同一枚半圆，转过半圈，沿直径错开。两片各自成层，可单独调节前后明暗。

菜单栏五态怎么看

A · 看轨迹未连接时上沿断开。分流时两条轨迹各走各的，叠加时合成一枚粗 P。主备只保留短备用轨，线路异常时右侧出现叹号。

B · 看斜缝未连接只留下两个断开的轮廓。分流时两块实色之间留一道斜缝，叠加时接成完整的 P。主备缩短备用片，线路异常时右侧出现叹号。

C · 看半圆未连接是两个空心半圆。分流时两片错开，叠加时对齐并在中央相连。主备用一条短线表示待命的一半，线路异常时右侧出现叹号。
