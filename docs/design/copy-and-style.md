## 2. 样式（macOS 26）

- 只用系统控件与语义色：`.background` / `.secondary` / `.tint` / 系统强调色；不手写颜色值，图表配色除外。
- Liquid Glass 只在系统给的地方（工具栏、侧栏、检查器、弹出面板）；内容区不自己画玻璃，不叠卡片阴影。
- 内容区用 `Form(.grouped)` 或 `List(.inset)`，不自己拼卡片；页边距用系统默认（不额外 `.padding(20)` 再套一层）。
- 字号：正文 `.body`，次要 `.callout`，说明 `.footnote` / `.caption`；数字一律 `.monospacedDigit()`。
- 空态：`ContentUnavailableView`，标题用表 1 的空态用词，最多一行说明，给一个主操作按钮（如「前往配置」）。
- 响应式：窗口最小 760×520；宽度不足时多列布局退成单列，表格列可隐藏；不出现横向滚动。
- 说明文字放在 Form 的 `footer` 或控件的 `.help`，不在页面顶部堆段落。
